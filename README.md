# 🎓 Student Performance Prediction using Machine Learning

## 📌 Overview

This project predicts student marks using a **Linear Regression** model based on various factors such as study hours, sleep duration, attendance, previous scores, internet access, and gender.

The project demonstrates a complete Machine Learning workflow, including data preprocessing, feature encoding, model training, prediction, and evaluation using Scikit-learn.

---

## 🚀 Features

- Load dataset using Pandas
- Data preprocessing
- Label Encoding for categorical features
- Feature selection
- Train-Test Split
- Linear Regression model
- Student marks prediction
- Model evaluation using:
  - Mean Absolute Error (MAE)
  - Mean Squared Error (MSE)
  - R² Score

---

## 🛠 Technologies Used

- Python
- Pandas
- Scikit-learn
- NumPy

---

## 📂 Dataset Features

| Feature | Description |
|----------|-------------|
| Hours | Study hours per day |
| Sleep | Sleep duration (hours) |
| Attendance | Attendance percentage |
| Previous_Score | Previous examination score |
| Internet | Internet availability (Yes/No) |
| Gender | Student gender |
| Marks | Target variable |

---

## 📊 Machine Learning Workflow

1. Load CSV Dataset
2. Explore Dataset
3. Encode Categorical Features
4. Select Features and Target
5. Train-Test Split
6. Train Linear Regression Model
7. Predict Student Marks
8. Evaluate Model Performance
